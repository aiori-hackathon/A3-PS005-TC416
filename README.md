# HORA Q

**Explainable BGP Origin and Subprefix Anomaly Monitor**

AIORI-3 Hackathon · PS-005 · Cyber Security

**Team Code:** A3-PS005-TC416  
**Institution:** Al-Ameen College

## Project Overview

HORA Q is a proposed routing-security investigation platform for detecting selected BGP origin-AS changes and newly observed more-specific prefixes.

The project combines historical routing analysis, cautious baseline promotion, evidence correlation, explainable findings, and ML-DSA-signed evidence records with independent verification.

## Proposed Technical Components

- Live BGP observation ingestion through RIPE RIS Live
- RPKI origin-validation context through RIPEstat
- Historical routing state and candidate-baseline policy
- Origin and subprefix anomaly detection
- Evidence correlation and explainability
- ML-DSA evidence signing and independent verification
- Reproducible scenario replay and benchmarking
